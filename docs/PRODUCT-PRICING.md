# SentinelOpsAI — Product & Pricing

## Product

SentinelOpsAI is an AI Agent Security and Governance platform designed to place a controlled security and policy layer between AI agents and consequential tools or actions.

The platform provides centralized policy evaluation, risk scoring, approval workflows, controlled execution, audit events, and tool integration boundaries.

**Current release:** v0.3.2

The current production demonstration verifies:

1. Allowed action

5. Runtime event and audit evidence
6. Agent, Tool and Policy management

## Important Scope Note

The current demonstration uses the `simulated` tool adapter.

This means the demonstrated execution flow validates SentinelOpsAI's authorization, policy, risk, approval, audit, and gateway controls without claiming that the demo performs real financial or destructive business operations.

Production integrations are configured according to the customer's infrastructure, tools, credentials, policies, and security requirements.
